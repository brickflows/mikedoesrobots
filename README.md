# mikedoesrobots.com

Portfolio site for Micheal Adediran. Static site built with [Astro](https://astro.build).

## Run it

```
npm install
npm run dev      # http://localhost:4321
npm run build    # static output in dist/
```

## Where things are

| Path | What |
|---|---|
| `src/pages/index.astro` | Home page: hero, work index, method table, about, blog |
| `src/pages/work/` | One file per case study |
| `src/pages/blog/` | One file per blog post; add each one to the `posts` list in `index.astro` |
| `src/pages/portfolio.astro` | The PDF portfolio as a page: page images in `public/media/portfolio/`, the PDF itself in `public/portfolio/` |
| `src/pages/portfolio-rfa.astro` | A second copy of the portfolio at `/portfolio-rfa/`, not linked from the nav and marked `noindex`: page images in `public/media/portfolio-rfa/`, PDF in `public/portfolio/` |
| `src/layouts/Base.astro` | Head, nav, contact footer and title block shared by every page |
| `src/styles/global.css` | All styles; colours and fonts are the variables at the top |
| `public/media/` | Web-sized images and video, generated by `scripts/prep-media.py` |
| `scripts/prep-media.py` | Rebuilds `public/media/` from the original renders, portfolio figures and farm frames in `Downloads` |
